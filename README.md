## ⚡ Comandos del Pipeline CLI
```bash
# Diagnóstico de librerías y dependencias
python gta6_faceless_pipeline.py --check

# Normalizar audio a -14 LUFS estándar YouTube
python gta6_faceless_pipeline.py --sanitize-audio audio.wav

# Renderizar Short 9:16 con crop dinámico
python gta6_faceless_pipeline.py --render-crp-9x16 input.mp4 short_render.mp4
```
